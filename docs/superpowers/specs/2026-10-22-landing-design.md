# Лендинг «Мини-инструмент за минуту»: дизайн

Дата: 2026-10-22. Идея C из подборки YC Fall 2026 («A Cloud for Small Software»). Предыдущая версия лендинга (бот для 1С) сохранена в `D:\Work\startupold`.

## Зачем

Страница рассказывает идею: конструктор маленьких рабочих инструментов для одного человека или небольшой команды. Читатель за десять секунд понимает, что можно собрать инструмент без программирования, и нажимает «Попробовать».

## Для кого

Человек, которому тесно в таблице, а заказывать программу долго и дорого. Не технарь. Слова «API», «LLM», «backend» на странице не нужны.

## Решения

- **Действие:** кнопка «Попробовать» ведёт на `try.html`.
- **Тон:** просто и по-деловому, на «вы», короткие фразы (как в прошлой версии).
- **Блоки:** первый экран, «Как это работает» (3 шага), «Как выглядит результат» (CSS-макет инструмента), «Что можно собрать» (4 шаблона), финальная кнопка.
- **Вид:** светлая страница, глубокий синий акцент, стили те же, что в прежнем лендинге.
- Один файл `index.html`, стили внутри, без внешних библиотек и картинок, телефон в приоритете.

## Не цели

- Страница «Попробовать» (`try.html`) в эту задачу не входит и будет сделана позже. До этого кнопки ведут на несуществующий файл.
- Нет форм, цен, отзывов, регистрации, серверной части.

## Открытые места

- Пример на странице (расходы на поездку, ссылка `mini.example/poezdka`) вымышлен и помечен как пример.
- Набор из четырёх шаблонов выбран исполнителем и может измениться при создании `try.html`.
