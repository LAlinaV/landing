# Карта проекта

## Что это
Лендинг идеи «Мини-инструмент за минуту» и MVP, который мы будем строить по задачам. Идея: конструктор маленьких рабочих инструментов для одного человека или небольшой команды. Человеку тесно в таблице, а заказывать программу долго и дорого. Он выбирает шаблон, называет поля, получает ссылку и делится ею. Без программирования. Страница должна за десять секунд объяснить это и подвести к кнопке «Попробовать». Подробности: `docs/superpowers/specs/2026-10-22-landing-design.md`.

## Что где лежит
- `index.html` — весь лендинг в одном файле (стили внутри, без библиотек).
- MVP вынесен в отдельный репозиторий `mvp` (`D:Workmvp`), сайт https://lalinav.github.io/mvp/. Кнопки «Попробовать» ведут туда.
- `docs/superpowers/specs/` — документы дизайна (что и зачем строим).
- `docs/agents/` — настройки для агентов: где живут задачи, метки, где доменные документы.
- `CLAUDE.md` — этот файл: карта проекта и правила для Claude.
- Прошлая версия лендинга (бот для 1С) лежит вне репозитория, в `D:\Work\startupold`.

## Как сайт публикуется
Сайт живёт на GitHub Pages. Сделали `git push` в ветку `master` — через минуту-две страница обновилась. Отдельной сборки нет, публикуется сам `index.html`. MVP публикуется отдельно из репозитория `mvp`. Адрес: https://lalinav.github.io/landing/

## Как мы работаем
Одна задача на GitHub (Issue) = одна новая сессия Claude. Берём задачу, открываем чистую сессию, делаем только её, закрываем задачу и коммитим. Так контекст не разрастается и не путается.
